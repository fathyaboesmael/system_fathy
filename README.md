# Employee Management System

A simple Employee Management System built with **Dart** to practice Object-Oriented Programming (OOP) concepts.

## Project Overview

This project simulates a basic company employee management system. It allows managing different types of employees, storing their personal information, handling salaries, and calculating bonuses.

## Features

* Manage employee information (ID, Name, Salary, Address).
* Support different employee types:

  * **Developer:** Stores programming language and years of experience.
  * **Designer:** Stores design tool and completed projects count.
* Display employee information.
* Calculate bonuses based on employee type.
* Practice inheritance and method overriding.

## OOP Concepts Applied

* Classes & Objects
* Encapsulation
* Inheritance
* Polymorphism
* Method Overriding
* Constructors
* Getters & Setters

## Getting Started

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Navigate to the project directory:

```bash
cd Employee-Management-System
```

3. Run the project:

```bash
dart run
```
